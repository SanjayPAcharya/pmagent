# 1 · Pending

Work that isn't build-ready yet: phase drafts, plus the [backlog](BACKLOG.md).

- **Stages here:**
  - `idea`: backlog lines only.
  - `draft`: Planning is shaping it.
  - `pm-review`: waiting for the Product Manager.
  - `blocked`: waiting on an owner decision (⛔).
  - `parked`: deliberately on hold.
- **Comes in:** Product Planning drafts it, from the backlog or an owner request.
- **Goes out:** the Product Manager checks it against the code and moves it to [`2-ready/`](../2-ready/).
- **Priority** is the Pending table on [BOARD.md](../../../BOARD.md), not file names.
- Drafts written before 2026-11-19 use the older layout. Planning or the PM adds the header line and Handoff log from the [template](../../workflow/templates/work-item.md) when they pick one up.
